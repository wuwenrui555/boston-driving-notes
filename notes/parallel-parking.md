# 平行停车（Parallel Parking）

## 流程

1. 找参照位置
   - 路考标准：前车尾对齐自己**后窗中线**

2. 倒入准备（静止准备口诀）
    - 档位：`R`
    - 方向盘：向右打到底
    - 打灯：右转灯
    - 后视镜：左后视镜（看左后方有无来车）
    - 盲区：左后车窗（左后盲区有无来车)

3. 倒入
    - 右肩回头看后车窗（看泊位 / 与前车距离）
    - 右手手放在副驾驶座椅上, 左手放在方向盘的12点位置 (方便打方向盘)
    - 全程头要看向后方, 不要明显得瞄镜子/前方, 以免监考官觉得你在"看镜子开车"
    - 松刹车后退, 直到车身呈 **45° 角**斜入, 刹车.
    - 注意:
        - 教练会说车的右前灯路过前车的左后灯的时候, 转过来看一眼看看会不会剐蹭到前车.
        - 有的教程会说后退到45度之后需要回正方向盘再后退一点点, 但教练说不需要, 直接45度就可以继续往后退了.

4. 摆正准备（静止准备口诀）
    - 档位：`R` (此时已经在 `R` 档了, 不需要换档)
    - 方向盘：向左打到底
    - 打灯：-
    - 后视镜：-
    - 盲区：-
    - 注意:
        - 教练说这时候不用打灯, 因为车已经在倒车了, 别人会注意和避让你.
        - 不需要重做镜+盲区, 因为这是同一个倒车动作中的方向盘切换, 不是新动作; 视野从未断开 (全程右肩回头看).

5. 摆正
    - 右肩回头看后车窗（看泊位 / 与前车距离）
    - 右手手放在副驾驶座椅上, 左手放在方向盘的12点位置 (方便打方向盘)
    - 全程头要看向后方, 不要明显得瞄镜子/前方, 以免监考官觉得你在"看镜子开车"
    - 松刹车后退, 直到车身与路边平行, 刹车.

6. 向前准备（静止准备口诀）
    - 档位：`D`
    - 方向盘：回正
    - 打灯：-
    - 后视镜：-
    - 盲区：-

7. 向前
    - 慢慢松刹车前进, 直到车完全进入泊位, 同时微调方向盘保持车身与路边平行
    - 刹车
    - 挂`P` 档。

8. 离开车位 → 按 [后退](./back-up.md) 流程拉开和前车距离 → 按 [Pull Over 起步](./pull-over.md#流程)（第 2 步）驶出

## 调整

### 情况 A：离路缘太远

来回切换 D 和 R：

1. D 段（静止启动口诀）
   - 档位：`D`
   - 方向盘：向左打一些
   - 打灯：-
   - 后视镜：-
   - 盲区：-

   前进一点 → 刹车

2. R 段（静止启动口诀）
   - 档位：`R`
   - 方向盘：向右打
   - 打灯：右转灯
   - 后视镜：-
   - 盲区：-

   后退调整。重复直到合适 → `P` 档。

### 情况 B：离前车太近（静止启动口诀）

- 档位：`D`
- 方向盘：回正
- 打灯：-
- 后视镜：-
- 盲区：-

完成后松刹车前进一点 → 刹车 → `P` 档

## 教练强调

- 路考**允许调整**——不要怕调整，**平行停车的本质就是调整**
- 完成后给后车留出空间，不要紧贴前车

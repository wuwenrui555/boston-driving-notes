# 三点掉头（Three-Point Turn / K-turn）

## 何时使用

道路太窄无法做 U-turn 时（教练举例：去 Bloomingdale 没找到入口要回头）。

## 流程

### 第一步 — 前进至对面路边

1. **左转灯**
2. 检查：前方 → 后视镜 → 左右后视镜 → 回头看左后盲区
3. 方向盘**向左打到底**
4. 松刹车前进（缓慢驶向对面路边）
5. 快到对面路缘时刹车 → `P` 档短暂停留
6. ⚠️ **不能压到或碰到路缘**

### 第二步 — 倒车至原车道路边

1. **右转灯** → `R` 档
2. 方向盘**向右打到底**
3. 检查：回头看右后方 + 左后视镜确认无来车
4. 右手放副驾座椅靠背，回头看
5. 松刹车后退 → 快到路缘时刹车 → `P` 档短暂停留

### 第三步 — 驶入对向车道

1. **左转灯** → `D` 档
2. 方向盘**向左打到底**
3. 检查左右来车
4. 松刹车前进
5. 驶入对向车道后方向盘回正 —— 完成

## 教练强调

- 三点掉头相对简单，但**每一步都要打灯 + 检查**，不能省
- 速度要快——别人在等你
- 前进/后退到路缘前**必须完全停住**，不能压线

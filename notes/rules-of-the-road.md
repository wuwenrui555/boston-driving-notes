# 行车规则与信号 (Rules of the Road)

## 1. 信号灯与路口规则

### 绿灯

- **绿灯直行**: 正常通过, 不用停
- **绿灯左转**:
    - 没有保护箭头 → 让对向直行车先走 (yield to oncoming), 然后趁空隙左转
    - 有绿色左转箭头 → 保护左转, 直接走
- **绿灯右转**: 直接走 (注意人行道上的行人)

### 黄灯

- **能安全停下就停下** (默认选择)
- 已经过了 stop line / 离路口太近, 继续通过 (不要急刹)
- 不要为了赶绿灯加速冲

### 红灯

#### 红灯右转 (Right Turn on Red)

MA 默认**允许**红灯右转, 除非有 `No Turn on Red` 路牌.

流程:

1. **完全停下** (在 stop line / 红灯前)
2. 慢慢往前探到能看到左边来车的位置, 再停一次
3. 让人行道行人 + 左侧来车先走
4. 路况安全后右转

#### 红灯左转

通常**不允许**, 除非:

- 单行道转单行道
- 有专门的允许牌子 (少见)

### 左转保护信号

| 信号 | 含义 |
| --- | --- |
| 绿色实心箭头 | 保护左转, 直接走 |
| 闪烁黄色箭头 | 让行后可以左转 (yield to oncoming) |
| 红色箭头 | 不能左转, 必须等 |

### 教练强调

- 黄灯时**默认停**, 除非真的来不及, 不要硬冲
- 红灯右转**必须先完全停**, 不能 "rolling stop" (慢慢溜过去)

## 2. 速度控制

### 一般原则

- **果断**: 路口判断好就走, 不要犹豫
- **不要太慢**: 限速以下太多 (例如 30 mph 区你开 15) 同样会扣分, 监考官会觉得你不熟练
- **不要太快**: 超速直接 fail
- 看到限速牌**立即调整**, 不要拖

### MA 常见限速 (默认)

| 区域 | 限速 (mph) |
| --- | --- |
| Thickly settled / 居民区 | 30 |
| 商业区 (business district) | 30 |
| 学校区 (school zone, 上下学时段) | 20 |
| 城市主路 / urban arterial | 35-45 |
| 乡村道路 (rural highway) | 40-55 |
| 高速公路 (interstate) | 55-65 (看路牌) |

> ⚠️ **如果路边没有限速牌**, MA 默认按 30 mph (城市内) 或路况合理速度.

### 教练强调

- "Don't go too slow", 慢车也是危险源
- 路考时不要因为紧张就刻意慢, 跟着限速走

## 3. 跟车距离

### 3 秒法则 (3-Second Rule)

跟前车保持至少 **3 秒**距离:

1. 选个固定参照物 (路标 / 树 / 桥 / 路面标志)
2. 前车经过参照物时, 开始默念 `one-thousand-one, one-thousand-two, one-thousand-three`
3. 你的车应该正好或稍后经过参照物
4. 数完 3 秒前就过 → 跟太近, 减速拉开

### 特殊情况要加大距离

| 情况 | 距离 |
| --- | --- |
| 雨天 / 雪天 / 路滑 | 4-6 秒 |
| 跟大车 (truck / bus) | 加大 (视野被挡, 也防止它急刹) |
| 高速公路 | 加大 (速度高, 反应距离也长) |
| 后面有车紧贴你 (被 tailgate) | 拉开和前车的距离 (给自己更多反应时间) |

### 教练强调

- 跟太近 (**tailgating**) 是常见扣分点
- 路考时**故意比平时拉开多一点**, 让监考官看到你保持安全距离

## 4. 学校区与校车

### 学校区 (School Zone)

- 上下学时段 (通常 7-9 am, 2-4 pm) 限速 **20 mph**
- 看到 `School Zone` 标志或闪黄灯, 立即减速
- 校车经过时**额外注意**儿童

### 校车闪红灯 (School Bus Stop Arm)

校车停下并伸出红色 stop arm 时:

| 你的位置 | 你怎么办 |
| --- | --- |
| 和校车**同方向** | **必须停下**, 直到 stop arm 收回 |
| 和校车**对向** (双向道, 无中央分隔) | **必须停下** |
| 和校车**对向** (有中央分隔, 如 median / barrier / divider) | 可以正常通过 |

> ⚠️ MA 法规: 不停车通过 stop arm 校车, 罚款很重 ($250+) + 扣分 + 路考直接 fail.

### 教练强调

- 看到校车减速 / 闪黄灯, **预判它马上会停**, 提前减速
- 即使 stop arm 没出来, 也要警惕儿童突然冲出
- 学校区即使没看到孩子也要按 20 mph 开

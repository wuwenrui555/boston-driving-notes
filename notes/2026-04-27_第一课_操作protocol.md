> 来源：现场笔记 + 录音转文字（`~/recordings/2026-04-27_练车_Crowninshield_Rd.m4a`）

## 0. 通用原则（贯穿所有操作）

### 双手

- 双手要"相对"（10-2 或 9-3 位置），不能同侧
- 转弯时双手要"换"（hand-over-hand），不要原地不动
- 这是教练判断"会不会开车"的第一眼指标——务必养成习惯

### 任何动作前的检查顺序

**口诀**：Signal → Mirror → Blind spot

起步、转弯、变道、停车、变道前都按这个顺序，一个都不能少。
原则：**所有事都要在车动起来之前准备好**——不要边动边查。

### 换档

- **先把刹车踩到底，再换档**——永远不要带速换档（会毁变速箱）
- 顺序铁律：**刹车 → 换档 → 松刹车**

### 刹车

- 不要急刹——想象仪表盘上有杯热咖啡，急刹就泼了
- 减速优先用"松油门 + 轻刹车"，要平顺

### 后视镜

- 后视镜会"骗你"，会让物体显得比实际更远——不能完全相信
- 必须配合盲区检查（回头看），后视镜只是辅助

### 观察

- 一直在扫视：远处的 stop sign、One Way 标志、对向车、行人
- 不要等到停下来才看牌子——远远看见就要反应
- "ladies see everything"——开车时也要看到所有标志

### 不要相信路边停的车

- 别人停的方向可能是错的（懒得调头逆向停）
- 用 One Way 箭头判断方向，不要用别人的车判断

## 1. 路口转弯

### 流程

1. 远处就开始观察路口情况、stop sign、对向来车
2. 提前打转向灯（不要临到路口才打）
3. T 字路口或有人行道处**停 2 次**：
   - 第一次：在 stop sign / 实线处**完全停下**
   - 第二次：松刹车蠕动到人行道前，再停一次确认
4. 调整好方向盘后踩油门**快速完成转向**
5. 转完后方向盘自动回正——手轻放即可

### 教练强调

- 转弯时双手要"换"，不要僵着
- 转完后果断加速到合适车速，不要拖

---

## 2. 路边停车（Pull Over）

### 停车流程

1. **右转灯**
2. 刹车减速（不要急刹）
3. 方向盘向右——慢速向右前方靠
4. 方向盘向左——慢速将车摆正
5. **车身完全平直后再停**——`P` 档

> ⚠️ 停下前一定要让车"直"。车身斜着停，后面再起步或做平行停车都会很麻烦，也是路考扣分点。

### 重新启动流程

1. 踩住刹车 → `D` 档
2. 方向盘向左
3. **左转灯**
4. 左后视镜 → 左后车窗（盲区）
5. 松刹车，向左前方驶出

---

## 3. 平行停车（Parallel Parking）

### 入位流程

#### 步骤 1 — 找参照位置

- **路考标准**：前车尾对齐自己**后窗中线**
- **真实生活**：前车后门角窗对齐自己门角窗（前车后部更外露一些）

#### 步骤 2 — 倒入

1. 停在参照位置 → **右转灯** → `R` 档
2. 方向盘**向右打到底**
3. 检查：右转灯 → 左后视镜 → 左后车窗（盲区）
4. 右手放副驾座椅靠背，**回头看**（余光观察与前车距离）
5. 松刹车后退——车身呈 **45° 角**斜入
6. 快到路边时刹车——回正方向盘——继续慢慢后退一点

#### 步骤 3 — 摆正

1. 方向盘**向左打到底**
2. 右手放副驾座椅靠背，回头看
3. 松刹车后退，到合适位置刹车

### 调整流程

#### 情况 A：离路缘太远

- `D` 档 → 方向盘向左打一些 → 前进一点 → 刹车
- `R` 档 → **右转灯** → 方向盘向右打 → 后退调整
- 重复直到合适 → `P` 档

#### 情况 B：离前车太近

- `D` 档 → 方向盘回正 → 松刹车前进一点 → 刹车 → `P` 档

### 教练强调

- 路考**允许调整**——不要怕调整，**平行停车的本质就是调整**
- 完成后给后车留出空间，不要紧贴前车
- 顺序铁律：**先刹车 → 再换档 → 再松刹车**，永远不要先换档再踩刹车

### 重新启动流程

1. 踩刹车 → `R` 档（先倒一点拉开和前车距离） → **左转灯**
2. 从左到右扫视：左后车窗 → 左后视镜 → 后视镜 → 右后视镜 → 右后车窗
3. 右手放副驾靠背，回头看
4. 松刹车后退
5. 之后按 Pull Over 重新启动流程驶出

## 4. 三点掉头（Three-Point Turn）

### 何时使用

道路太窄无法做 U-turn 时（教练举例：去 Bloomingdale 没找到入口要回头）。

### 流程

#### 第一步 — 前进至对面路边

1. **左转灯**
2. 检查：前方 → 后视镜 → 左右后视镜 → 回头看左后盲区
3. 方向盘**向左打到底**
4. 松刹车前进（缓慢驶向对面路边）
5. 快到对面路缘时刹车 → `P` 档短暂停留
6. ⚠️ **不能压到或碰到路缘**

#### 第二步 — 倒车至原车道路边

1. **右转灯** → `R` 档
2. 方向盘**向右打到底**
3. 检查：回头看右后方 + 左后视镜确认无来车
4. 右手放副驾座椅靠背，回头看
5. 松刹车后退 → 快到路缘时刹车 → `P` 档短暂停留

#### 第三步 — 驶入对向车道

1. **左转灯** → `D` 档
2. 方向盘**向左打到底**
3. 检查左右来车
4. 松刹车前进
5. 驶入对向车道后方向盘回正 —— 完成

### 教练强调

- 三点掉头相对简单，但**每一步都要打灯 + 检查**，不能省
- 速度要快——别人在等你
- 前进/后退到路缘前**必须完全停住**，不能压线

## 5. 盲区参考（Blind Spot Reference）

### 后视镜里看车的位置

- 旁边车辆的前部出现在**自己驾驶座门把手位置** → 表示在盲区内
- ⚠️ 这个参考**只在邻车与自己车同尺寸时有效**：
  - 旁边是 Porsche / 小车 → 参考点偏前，不准
  - 旁边是 minivan / 校车 → 参考点偏后，不准

### 因此：盲区必须**回头看**，不能只信后视镜

- 回头幅度大一些（教练戏称类似"拥抱副驾"）
- 右手放副驾座椅靠背是辅助回头的姿势

---

## 6. 路考 vs 真实生活

| 操作 | 路考要求 | 真实生活 |
|------|---------|---------|
| 平行停车参照 | 前车尾对齐自己后窗中心 | 前车后部可以更外露一些 |
| 盲区检查 | 必做（哪怕没必要） | 视情况 |
| 转向灯 | 必打（哪怕没车） | 视情况 |
| 双手姿势 | 严格相对 | 大多数人不规范 |

> "Nobody does this in real life, but if you don't do it you won't pass."

---

## 7. 教练反馈与下一步

### 现阶段问题

- **双手姿势**——经常忘记 hand-over-hand，要有意识训练
- **刹车/油门不够果断**——该加速时拖、该平顺停时太硬
- **起步前的检查顺序**还不够流畅，需要变成肌肉记忆

### 总体建议

- 一节课最好 **1.5–2 小时**（1 小时太赶）
- 总课时建议至少 **20 小时**——别为了省钱牺牲安全
- 平时和家人/朋友再多练，但要练对的方法

### 下一节课重点

- 坡道停车（hill parking）——方向盘要打回，今天这点忘了
- 平行停车反复练习"调整"动作

# 平行停车（Parallel Parking）

## 入位流程

### 步骤 1 — 找参照位置

- **路考标准**：前车尾对齐自己**后窗中线**
- **真实生活**：前车后门角窗对齐自己门角窗（前车后部更外露一些）

### 步骤 2 — 倒入

1. 停在参照位置 → **右转灯** → `R` 档
2. 方向盘**向右打到底**
3. 检查：右转灯 → 左后视镜 → 左后车窗（盲区）
4. 右手放副驾座椅靠背，**回头看**（余光观察与前车距离）
5. 松刹车后退——车身呈 **45° 角**斜入
6. 快到路边时刹车——回正方向盘——继续慢慢后退一点

### 步骤 3 — 摆正

1. 方向盘**向左打到底**
2. 右手放副驾座椅靠背，回头看
3. 松刹车后退，到合适位置刹车

## 调整流程

### 情况 A：离路缘太远

- `D` 档 → 方向盘向左打一些 → 前进一点 → 刹车
- `R` 档 → **右转灯** → 方向盘向右打 → 后退调整
- 重复直到合适 → `P` 档

### 情况 B：离前车太近

- `D` 档 → 方向盘回正 → 松刹车前进一点 → 刹车 → `P` 档

## 教练强调

- 路考**允许调整**——不要怕调整，**平行停车的本质就是调整**
- 完成后给后车留出空间，不要紧贴前车
- 顺序铁律：**先刹车 → 再换档 → 再松刹车**，永远不要先换档再踩刹车

## 重新启动流程

1. 踩刹车 → `R` 档（先倒一点拉开和前车距离） → **左转灯**
2. 从左到右扫视：左后车窗 → 左后视镜 → 后视镜 → 右后视镜 → 右后车窗
3. 右手放副驾靠背，回头看
4. 松刹车后退
5. 之后按 [Pull Over](../pull-over/README.md#重新启动流程) 重新启动流程驶出

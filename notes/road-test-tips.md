# 路考应试技巧（Road Test Tips）

路考必做事项、常见扣分点、应试策略。

## 必做（漏一个就可能 fail）

### 任何动作前的检查顺序

**口诀**：Signal → Mirror → Blind spot

- 起步、转弯、变道、停车——一律按此顺序
- **哪怕路上没车也要打灯、查盲区**
- 监考官看的是动作是否完整，而不是有没有实际意义

### 双手姿势

- 始终保持 10-2 或 9-3 位置
- 转弯时双手"换"（hand-over-hand），不要原地不动
- 单手 / 同侧握 / 拳头握 = 扣分

### 换档前刹车踩到底

- 永远不要带速换档（扣分 + 毁变速箱）
- 顺序铁律：**踩刹车 → 换档 → 松刹车**

### Stop sign 路口要停 2 次

- 第一次：在 stop sign / 实线处**完全停下**
- 第二次：松刹车蠕动到人行道前再停一次确认

### 三点掉头不能压路缘

- 前进/后退到路缘前必须**完全停住**
- 碰到 / 压到路缘 = 可能直接 fail

### 路边停车 / 平行停车后车身要直

- 完成动作后车身必须与路缘平行
- 车斜着停 = 扣分（且后续起步会很难看）

## 常见扣分点

| 项 | 详情 |
| --- | --- |
| 不打转向灯 | 哪怕周围没车也必须打 |
| 不查盲区 | 哪怕死路也必须回头看 |
| 转弯犹豫 | 判断好了就要果断走，不要拖 |
| 跟车太近 | 保持安全车距（tailgating） |
| 双手姿势 | 单手 / 不"换"手 都扣 |
| 急刹 | 想象副驾上有热咖啡——平顺减速 |
| 起步前没检查 | Signal → Mirror → Blind spot 一个都不能少 |
| 停车斜了 | 路边/平行停车完车身不直 |

## 应试技巧

### 平行停车允许调整

- 路考时停下来调整**不会直接扣分**——不要怕调整
- 一次到位的人很少，监考官知道
- 调整流程见 [parallel-parking](./parallel-parking.md#调整)

### 路考 vs 真实生活

路考要求比真实生活严格。**先按路考标准练成肌肉记忆，再考虑现实变通**。

| 操作 | 路考要求 | 真实生活 |
| --- | --- | --- |
| 平行停车参照 | 前车尾对齐自己后窗中心 | 前车后部可以更外露 |
| 盲区检查 | 必做（哪怕没必要） | 视情况 |
| 转向灯 | 必打（哪怕没车） | 视情况 |
| 双手姿势 | 严格相对 | 大多数人不规范 |

> "Nobody does this in real life, but if you don't do it you won't pass."

### 课时投入

- 一节课 **1.5–2 小时**（1 小时太赶）
- 总课时至少 **20 小时**（教练建议）
- 别为了省钱牺牲安全和考试通过率

# 通用原则（General Principles）

贯穿所有操作的基本规则与好习惯。

## 双手（Hand Position）

- 双手要"相对"（10-2 或 9-3 位置），不能同侧
- 转弯时双手要"换"（hand-over-hand），不要原地不动
- 这是教练判断"会不会开车"的第一眼指标——务必养成习惯

## 两个 5 要素口诀

所有操作都可以归到两类。每个具体操作的笔记里都按对应口诀列出 1-5 步具体内容；某项不需要时用 `-` 占位。

### A. 静止启动 / 换方向

车从停止状态开始动，或者换前进/后退方向（变档）。

1. 档位
2. 方向盘
3. 打灯
4. 后视镜
5. 盲区

5 步全做完，再松刹车 / 给油执行。

**适用**：Pull over 起步；平行停车（入位 / 摆正 / 调整 / 起步）；三点掉头（3 步全部）。

### B. 连续移动

车一直在动，方向盘 = 执行动作本身。

1. 档位（一般为空）
2. 打灯
3. 后视镜
4. 盲区
5. 方向盘 + 执行

注意 4-5 顺序：**先镜+盲区，后方向盘+执行**。因为方向盘动作就是转弯本身，必须先确认无车。

**适用**：路口转弯；变道；Pull over 停车。

### 共同原则

- **打灯越早越好**——告知别人意图，不要临到动作才打
- **所有事都要在车动起来之前准备好**——不要边动边查
- 哪怕路上没车也要打灯、查镜、查盲区

## 换档（Gear Change）

- **先把刹车踩到底，再换档**——永远不要带速换档（会毁变速箱）
- 顺序铁律：**刹车 → 换档 → 松刹车**

## 刹车（Braking）

- 不要急刹——想象仪表盘上有杯热咖啡，急刹就泼了
- 减速优先用"松油门 + 轻刹车"，要平顺

## 后视镜（Mirrors）

- 后视镜会"骗你"，会让物体显得比实际更远——不能完全相信
- 必须配合盲区检查（回头看），后视镜只是辅助

## 观察（Observation）

- 一直在扫视：远处的 stop sign、One Way 标志、对向车、行人
- 不要等到停下来才看牌子——远远看见就要反应
- "Ladies see everything"——开车时也要看到所有标志

## 不要相信路边停的车

- 别人停的方向可能是错的（懒得调头逆向停）
- 用 One Way 箭头判断方向，不要用别人的车判断

## 教练总体反馈与下一步

### 现阶段问题（2026-04-27）

- **双手姿势**——经常忘记 hand-over-hand，要有意识训练
- **刹车/油门不够果断**——该加速时拖、该平顺停时太硬
- **起步前的检查顺序**还不够流畅，需要变成肌肉记忆

### 上课建议

- 一节课最好 **1.5–2 小时**（1 小时太赶）
- 总课时建议至少 **20 小时**——别为了省钱牺牲安全
- 平时和家人/朋友再多练，但要练对的方法

### 下一节课重点

- 坡道停车（hill parking）——方向盘要打回
- 平行停车反复练习"调整"动作

# Pre-Trip 考前检查

路考开始前, 监考官会让你坐在驾驶座先做的三件事. 这部分很多人忽略, 但**做不出来直接不让上路**.

## 1. 手势 (Hand Signals)

万一转向灯坏了, 用手势告诉别的司机你的意图. 从驾驶座窗户**伸左手出去**:

| 意图 | 手势 |
| --- | --- |
| 左转 | 左臂**直直水平**伸出窗外 |
| 右转 | 左臂伸出, **小臂向上 90°** (像举手) |
| 减速 / 停车 | 左臂伸出, **小臂向下 90°** (指向地面) |

监考官会让你直接在车里示范这三个.

## 3. 上下坡靠路牙子的方向盘 (Hill Parking)

MA 路考必考点. 规则:

| 情况 | 方向盘往哪打 | 原理 (车停在右路缘) |
| --- | --- | --- |
| **上坡 + 有路牙子** | 向**左**打 (远离路牙) | 车后溜 + 方向盘左 → 车尾甩向左, **车头向右**, 右前轮抵住路牙 |
| **下坡 + 有路牙子** | 向**右**打 (朝向路牙) | 车前溜 + 方向盘右 → **车头向右**, 右前轮抵住路牙 |
| **任何坡度 + 没路牙子** | 向**右**打 (朝向路边) | 不管前溜还是后溜, 车都偏向右侧, 滑向草地 / 路肩, 不会滑入马路 |

记忆: 车要滑 → 我让它滑去安全的地方 (有 curb → 撞 curb, 没 curb → 滑出路面)

完成后还要做:

1. 拉**手刹** (parking brake)
2. 挂 **`P`** 档
3. 松脚刹

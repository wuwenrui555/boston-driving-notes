# 跟车距离 (Following Distance)

## 3 秒法则 (3-Second Rule)

跟前车保持至少 **3 秒**距离:

1. 选个固定参照物 (路标 / 树 / 桥 / 路面标志)
2. 前车经过参照物时, 开始默念 `one-thousand-one, one-thousand-two, one-thousand-three`
3. 你的车应该正好或稍后经过参照物
4. 数完 3 秒前就过 → 跟太近, 减速拉开

## 特殊情况要加大距离

| 情况 | 距离 |
| --- | --- |
| 雨天 / 雪天 / 路滑 | 4-6 秒 |
| 跟大车 (truck / bus) | 加大 (视野被挡, 也防止它急刹) |
| 高速公路 | 加大 (速度高, 反应距离也长) |
| 后面有车紧贴你 (被 tailgate) | 拉开和前车的距离 (给自己更多反应时间) |

## 教练强调

- 跟太近 (**tailgating**) 是常见扣分点
- 路考时**故意比平时拉开多一点**, 让监考官看到你保持安全距离

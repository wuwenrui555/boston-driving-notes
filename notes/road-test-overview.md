# MA Class D 路考概览

按路考复习维度整理所有考点, 以及对应笔记的链接. 这页是**考前索引**，不是仓库目录.

> ⚠️ MA 路考评分表 (Class D Road Test Score Sheet) 是 RMV 内部文档, 网上摘录不一定完整. 实际考试以监考官现场评分为准.

## 1. 考前 (在驾驶座坐好之后)

先看 [Pre-Trip 考前检查](./pre-trip.md):

- 手势 (left turn / right turn / stop)
- 车内控制 (signals / wipers / defrost / lights / horn / brake)
- 上下坡靠路牙子方向盘

## 2. 基本操控

所有操作都会看这几项, 见 [通用原则](./general-principles.md):

- 双手姿势 (9-3 / 10-2, hand-over-hand)
- 脚位 (默认在脚刹, 松脚刹实现低速)
- 换档 (脚刹 → 换档 → 松脚刹)
- 刹车 (不急刹, 平顺减速)

## 3. 安全意识

这部分也主要看 [通用原则](./general-principles.md):

- 后视镜
- 观察 (远处扫视)
- 看哪边: 横穿 vs 汇入 (也在 [README](../README.md) 里)

## 4. 速度与跟车

- [行车规则与信号](./rules-of-the-road.md): 含限速规则, 跟车距离, 学校区时段限速, 校车 stop arm

## 5. 路口

- [路口转弯 (stop sign / 人行道)](./intersection-turn.md): 含什么时候停 2 次, 如何完成转弯
- [行车规则与信号 (绿/黄/红 + 红灯右转 + 左转保护)](./rules-of-the-road.md)

## 6. 操作题

- [路边停车序列 (Pull Over → Back Up → Pull Out)](./pull-over.md)
- [平行停车](./parallel-parking.md)
- [三点掉头](./three-point-turn.md)
- 上下坡停车: 见 [Pre-Trip 第 3 节](./pre-trip.md)

> 这一组可以理解为 examiner 常抽的低速操作题.

## 7. 应试策略 (非操作类)

最后再回看 [通用原则](./general-principles.md):

- 路考 vs 真实生活
- 学车课时建议

## 两个核心口诀

详见 [README](../README.md):

- A. 静止口诀: 档位 → 方向盘 → 打灯 → 后视镜 → 盲区
- B. 行进口诀: 打灯 → 后视镜 → 盲区 → 方向盘 + 执行

# MA Class D 路考概览

按考试评分类别列出所有考点, 以及对应笔记的链接.

> ⚠️ MA 路考评分表 (Class D Road Test Score Sheet) 是 RMV 内部文档, 网上摘录不一定完整. 实际考试以监考官现场评分为准.

## 1. 考前 (在驾驶座坐好之后)

监考官会让你示范, 见 [Pre-Trip 考前检查](./pre-trip.md):

- 手势 (left turn / right turn / stop)
- 车内控制 (signals / wipers / defrost / lights / horn / brake)
- 上下坡靠路牙子方向盘

## 2. 基本操控

跨在所有操作里, 见 [通用原则](./general-principles.md):

- 双手姿势 (9-3 / 10-2, hand-over-hand)
- 脚位 (默认在脚刹, 松脚刹实现低速)
- 换档 (脚刹 → 换档 → 松脚刹)
- 刹车 (不急刹, 平顺减速)

## 3. 安全意识

见 [通用原则](./general-principles.md):

- 后视镜
- 观察 (远处扫视)
- 看哪边: 横穿 vs 汇入 (也在 [README](../README.md) 里)

## 4. 速度与跟车

- [速度控制](./speed-control.md): 限速规则, 不要太慢也不要太快
- [跟车距离](./following-distance.md): 3 秒法则
- [学校区与校车](./school-zones-bus.md): 校车 stop arm, 学校时段限速

## 5. 路口

- [路口转弯 (stop sign / 人行道)](./intersection-turn.md): 含什么时候停 2 次
- [信号灯路口 (绿/黄/红 + 红灯右转 + 左转保护)](./traffic-signals.md)

## 6. 操作题 (随机抽考)

- [路边停车序列 (Pull Over → Back Up → Pull Out)](./pull-over.md)
- [平行停车](./parallel-parking.md)
- [三点掉头](./three-point-turn.md)
- 上下坡停车: 见 [Pre-Trip 第 3 节](./pre-trip.md)

## 7. 应试策略 (非操作类)

见 [通用原则](./general-principles.md):

- 路考 vs 真实生活
- 学车课时建议

## 两个核心口诀

详见 [README](../README.md):

- A. 静止口诀: 档位 → 方向盘 → 打灯 → 后视镜 → 盲区
- B. 行进口诀: 打灯 → 后视镜 → 盲区 → 方向盘 + 执行

## 小技巧

### 两个口诀

所有操作考点都可以归到两类, 用口诀记住操作.

#### A. 静止口诀 (车没动起来时: 起步, 换方向, 变档前的检查)

1. 档位
2. 方向盘
3. 打灯
4. 后视镜
5. 盲区

**适用**: Pull over 起步, 平行停车, 三点掉头.

#### B. 行进口诀 (车一直在动, 方向盘 = 执行动作本身)

1. 打灯
2. 后视镜
3. 盲区
4. 方向盘

**适用**: 路口转弯, 变道, Pull over 停车.

### 看镜+盲区方向

**本质**: 看**可能撞你的车从哪一侧来**.

| 类型 | 看哪边 |
| --- | --- |
| 横穿马路 (三点掉头, U-turn, 出停车场穿过整条路) | 两侧都有来车 → **左右都看** |
| 沿车道汇入 / 转弯 / 倒车 | 别人正常行驶可能撞你的空间 = 你的车体 (车头) 要侵入的空间  → **看车头摆向那一侧** |

- **前进时**: 车头摆向 = 方向盘方向
- **倒车时**: 车头摆向 = 方向盘**反方向** (后退时, 车尾摆向 = 方向盘方向)
